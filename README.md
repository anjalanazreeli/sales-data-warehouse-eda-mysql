Project Title
Sales Data Warehouse Exploratory Data Analysis (SQL)
Project Overview
This project focuses on executing a structured Exploratory Data Analysis (EDA) on a dimensional sales data warehouse using SQL. Guided by the framework taught by Data with Baraa, the objective is to explore the underlying database architecture, profile qualitative dimensions, analyze quantitative sales measures, and extract key commercial insights regarding sales trends, product performance, and customer purchasing behaviors.
Key Objectives & Analytical Steps
1. Database & Schema Exploration: Inspected metadata, table structures, relationships, and primary/foreign keys across fact (⁠fact_sales⁠) and dimension (⁠dim_customers⁠, ⁠dim_products⁠) tables in the ⁠gold⁠ schema.
2. Dimension Profiling: Explored qualitative fields to understand customer demographics, geographic distribution, product categorization, and overall data scope.
3. Date & Range Analysis: Determined order timeframes, tracking customer activity across order history boundaries (⁠first_order_date⁠ to ⁠last_order_date⁠).
4. Measures & Aggregation: Calculated key performance indicators (KPIs) such as total revenue, total sales volume, and order frequency using SQL aggregate functions (⁠SUM⁠, ⁠COUNT⁠) combined with relational joins (⁠LEFT JOIN⁠).
5. Ranking & Segmentation Analysis: Ranked top and bottom performing product lines and customer segments using filtering and sorting techniques (⁠GROUP BY⁠, ⁠ORDER BY⁠, ⁠LIMIT⁠).
Technical Skills Applied
 SQL Queries & Clauses: ⁠SELECT⁠, ⁠WHERE⁠, ⁠GROUP BY⁠, ⁠HAVING⁠, ⁠ORDER BY⁠, ⁠LIMIT⁠
 Joins & Data Relationships: ⁠LEFT JOIN⁠, ⁠INNER JOIN⁠ (linking fact tables with dimension tables)
 Aggregations: ⁠SUM()⁠, ⁠COUNT()⁠, ⁠COUNT(DISTINCT)⁠
 Database Management: MySQL Workbench
